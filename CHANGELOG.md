- `Singularity/Portfolio/Mixed.lean`: Lemmas 10.3, 10.4 and 10.5 of research note 10. The handbook numbers are not fixed yet. Let `R` have characteristic `p`, let `f` have degree `m = p^e m_0` with `p ∤ m_0`, and let `a_i` be the coefficient of `z^(m-i)`. The theorem of Lucas of Mathlib gives `binom(p^e m_0, p^e) ≡ m_0` modulo `p` (`Portfolio.choose_pow_mul_pow_modEq`, `Portfolio.cast_choose_pow_mul_pow_lucas`), and `binom(p^e m_0, k) ≡ 0` modulo `p` if `p^e ∤ k` (`Portfolio.choose_pow_mul_modEq_zero`, `Portfolio.cast_choose_pow_mul_eq_zero_lucas`). Lemma 10.3: for monic `f`, the translation `z ↦ z + c` gives `a'_(p^e) = a_(p^e) + m_0 c^(p^e) + ∑_(0 < j < p^e) binom(m - j, p^e - j) a_j c^(p^e - j)` (`Portfolio.lucas_tschirnhausen`, `Portfolio.lucas_tschirnhausen_of_eq_zero`). Over a perfect field, if `a_1 = ... = a_(p^e - 1) = 0`, a translation makes `a_(p^e) = 0` (`Portfolio.exists_lucas_tschirnhausen_eq_zero`). Lemma 10.4: for `0 < i < p^e`, `a'_i = a_i + ∑_(0 < j < i) binom(m - j, i - j) a_j c^(i-j)` (`Portfolio.inseparable_layer_rigid`). So `a'_i = a_i` if `a_1 = ... = a_(i-1) = 0` (`Portfolio.inseparable_layer_rigid_of_eq_zero`), and `a'_1 = a_1` if `e ≥ 1` (`Portfolio.inseparable_layer_rigid_one`). A polynomial is in `((z) + I R[z])^n` if and only if its coefficient of `z^k` is in `I^(n-k)` for each `k` (`Portfolio.mem_span_X_sup_map_C_pow_iff`). Lemma 10.5: let `q = p^e`, let `I ≠ R` and let `J = (z - h) + I R[z]`. Then `z^q + g ∈ J^n` if and only if `n ≤ q` and `g + h^q ∈ I^n` (`Portfolio.X_pow_add_C_mem_pow_iff_order`). So `z^q + g ∈ J`, `z^q + g ∈ J^q` and `z^q + g ∉ J^(q+1)` if and only if `g + h^q ∈ I^q` (`Portfolio.lift_base_blowup`). If a ring map `φ` sends `I` into `(x)`, then the substitution `z = h + x z''` sends `z^q + g` to `x^q (z''^q + g'')` with `x^q g'' = φ(g + h^q)` (`Portfolio.lift_base_blowup_chart`). The order along `J` uses the ordinary powers of `J`, not the order at the generic point of the centre. The permissibility of the blowup and the strict transform as a scheme are not proved.

## 0.4.42 - 2026-11-27

### Added

- `Singularity/Example/CurveNormalization.lean`: the normalization of the cusp, the node and the Whitney umbrella (Volume 1, Examples 2.5.8, 2.5.9 and 2.5.10 of the handbook). Let `C` be a domain with field of fractions `K` and let `B` be a subalgebra of `C`. If `c C ⊆ B` for some `c ≠ 0`, then `K` is the field of fractions of `B` (`isFractionRing_of_mul_mem`). A polynomial is in `k[t^2, t^3]` if and only if its coefficient of `t` is `0` (`mem_cusp_iff`), and the conductor is `t^2 k[t]` (`mul_mem_cusp_iff`). If `2 ≠ 0` in `k`, a polynomial `p` is in `k[t^2 - 1, t^3 - t]` if and only if `p(1) = p(-1)` (`mem_node_iff`), and the conductor is `(t^2 - 1) k[t]` (`mul_mem_node_iff`). The ideal `y k[y, t]` is in `k[y, yt, t^2]` (`umbrella_mul_mem`). The file starts from the subalgebras, so it does not prove that the quotients of the handbook are isomorphic to them.

For `δ ∈ ℤ^k`, let `Φ(δ) = min(P, Q)`, where `P` is the sum of the positive entries and `Q` is minus the sum of the negative entries (`OriginRuns.phi`). The origin of the `x_j`-chart sends `g` to `x_j^p g'`, where the exponent `e` of each monomial changes by `e_j ← |e| - p` (`OriginRuns.expStep`, `OriginRuns.pointChart_eq_X_pow_mul_originTransform`). If `g` is clean and has a least exponent, then `G` is a unit and `ρ = 0` (`OriginRuns.logJacobianOrder_eq_zero`), and this stays true at each later point (`OriginRuns.originRun_unit_stays`). ## 0.2.11 - 2026-11-24

### Added

- `Singularity/Algebra/FiniteDifference.lean`: a function $f : \mathbb{N} \to \mathbb{Z}$ is eventually polynomial of degree less than $d$ (`IsEventuallyPolynomial f d`) if it agrees for large $n$ with a polynomial in $\mathbb{Q}[X]$ of degree less than $d$. The file proves that this holds if and only if $\Delta^d f$ is eventually $0$, and it proves the laws for sums, partial sums and shifts. It also defines the eventual value of a function that is eventually constant.
- `Singularity/Algebra/HilbertSerre.lean`: the theorem of Hilbert and Serre (`isEventuallyPolynomial_length_of_grading`). Let $N = \bigoplus_n N_n$ be a Noetherian module over an $R$-algebra generated by $r$ elements that raise the degree by $1$, with each $N_n$ of finite length. Then $n \mapsto \ell(N_n)$ is eventually a polynomial of degree less than $r$. The proof is by induction on $r$ with the kernel and the cokernel of the last generator [AM69, Theorem 11.1]. The file applies the theorem to the associated graded module of $M$ for $I$. Thus, if $R$ is Noetherian, $M$ is finite, $I$ has $r$ generators and $M/IM$ has finite length, the Hilbert-Samuel function is eventually a polynomial of degree at most $r$ (`exists_hilbertSamuel_polynomial`).
- `Singularity/Algebra/Multiplicity.lean`: the Samuel multiplicity `samuelMultiplicity I M d`, the eventual value of $\Delta^d$ of the Hilbert-Samuel function. It is $d!$ times the coefficient of $n^d$ of the polynomial (`samuelMultiplicity_eq_coeff`), it is $0$ above the degree, and it is positive at the degree when $R$ is local, $I$ is in the maximal ideal and $M \neq 0$ (`samuelMultiplicity_pos`). A larger ideal gives a smaller multiplicity (`samuelMultiplicity_anti`). A field and a discrete valuation ring have multiplicity $1$ (`samuelMultiplicity_field`, `samuelMultiplicity_dvr`). The value $1$ for each regular local ring is not yet proved.
- `Singularity/Algebra/MultiplicityRegular.lean`: let $R$ be a regular local ring of dimension $d$ with maximal ideal $\mathfrak m$. Then $\ell(R/\mathfrak m^{n+1}) = \binom{n+d}{d}$ for each $n$ (`hilbertSamuel_succ_eq_choose`), $\ell(\mathfrak m^n/\mathfrak m^{n+1}) = \binom{n+d-1}{d-1}$ for $d \geq 1$ (`length_grPiece_eq_choose`), and the multiplicity $e_d(\mathfrak m, R)$ is $1$ (`samuelMultiplicity_regular`). The proof does not use the associated graded ring. The main step is $(\mathfrak m^{n+1} : a) = \mathfrak m^n$ for the first element $a$ of a regular sequence that generates $\mathfrak m$. It comes from a general fact: if $I$ is generated by a weakly regular sequence in the maximal ideal of a Noetherian local ring and $z$ is a nonzerodivisor on $R/I$, then $z$ is a nonzerodivisor on each $R/I^n$ (`mem_pow_of_mul_mem_of_isWeaklyRegular`). The result holds for each Noetherian local ring whose maximal ideal is generated by a weakly regular sequence (`hilbertSamuel_succ_of_isWeaklyRegular`).
